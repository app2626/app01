(Mobile Pre-Order / Pre-Order / Invoice System) 

## สิทธิ์ผู้ใช้งาน (Roles)
- **Admin**: เข้าถึงทุกเมนู แก้ไขข้อมูลทุกตาราง จัดการตั้งค่าระบบ เห็นข้อมูลสดเสมอ (ไม่ผ่าน cache)
- **Manager**: เห็นข้อมูลทุกสาขา แก้ไขออเดอร์ได้เฉพาะสถานะออเดอร์ เข้าหน้ารายงาน/เป้าได้
- **Sales**: เห็น/บันทึกได้เฉพาะสาขาตัวเอง ใช้งานหน้า Pre-Order เป็นหลัก

Login มีระบบ "จดจำ Username/Password" (เก็บใน localStorage เครื่องนั้นๆ), rate-limit 5 ครั้ง/5 นาทีกันเดารหัสผ่าน

## หน้า Pre-Order / การจอง (Checkout)
- เลือกสาขา/ช่องทางขาย → เลือกสินค้า (ค้นหา/กรองตามหมวดหมู่+ความจุ+ราคา) → เพิ่มตะกร้า
- ระบบของแถมอัตโนมัติตาม GiftMappings (ผูกกับ Model/Product Group + Channel) และโปรโมชั่น Auto Bundle
- จำกัดสินค้าหมวด "โมบาย" ได้ 1 เครื่อง/ออเดอร์ (บังคับฝั่ง server)
- ฟอร์มข้อมูลลูกค้า: ชื่อ/เบอร์/อีเมล/บัตรประชาชน, ค้นหาลูกค้าเก่าจากเบอร์โทร (auto-fill), เลขที่ Pre Order, รอบรับเครื่องลูกค้าวันที่ (ช่วงวันที่พิมพ์อิสระ), รหัสลงทะเบียน (Code Handraiser)
- ประเภทสิทธิ์การจอง (จอง T มัดจำจริง / จอง F สวมสิทธิ์แคมเปญ) พร้อมเลขที่ใบเสร็จ+จำนวนเงินมัดจำ
- พิมพ์ใบจองหลังยืนยัน — เดสก์ท็อป: popup + print dialog ปกติ; มือถือ/แท็บเล็ต (จอ ≤1024px): สร้างไฟล์ PDF ดาวน์โหลดตรง (ใช้ html2canvas + jsPDF)

## จัดการสินค้า (Products)
- ตารางแอดมินมาตรฐาน (ค้นหา/กรอง/เรียง/export CSV) — ทุกคอลัมน์รวม Marketing Model, Price, Original Price
- **เพิ่ม/แก้ไขสินค้าแบบหลาย SKU**: กรอกข้อมูลร่วม (Model *, Marketing Model *, ความจุ *, Product Group, หมวดหมู่, ราคา, ราคาเดิม, รูปเริ่มต้น, ช่องทางขาย) ครั้งเดียว แล้วเพิ่มได้หลาย SKU (สี/สต๊อก/รูปเฉพาะ SKU) ในฟอร์มเดียว
  - พิมพ์ Model ที่มีอยู่แล้ว → โหมด "เพิ่ม SKU เข้าสินค้าเดิม" อัตโนมัติ (ฟิลด์ร่วมล็อกตามของเดิม)
  - แก้ไข = แก้ไขทั้งกลุ่ม SKU ของ Model นั้น เพิ่ม/ลบ/แก้ SKU ได้อิสระในหน้าเดียว เปลี่ยนชื่อ Model ไม่ได้
  - ชื่อสินค้า (Product Name) สร้างอัตโนมัติจาก Model + ความจุ + สี ไม่ต้องพิมพ์เอง

## จัดการออเดอร์ (Orders)
- ตารางแอดมิน แสดงทุกคอลัมน์บนทุกอุปกรณ์ (เลื่อนแนวนอนได้)
- แก้ไขออเดอร์เต็มรูปแบบ (Admin), แก้ได้เฉพาะสถานะ (Manager)
- ระบบสต๊อกปรับอัตโนมัติตามการเปลี่ยนสถานะ/แก้ไข/ลบออเดอร์ พร้อม log ที่ InventoryLog
- พิมพ์ย้อนหลัง (reprint) ใบจองจากแถวออเดอร์ที่มีอยู่

## Dashboard
- KPI สรุปยอด, กราฟยอดขายรายวัน, วิเคราะห์ยอดตามโมเดลสินค้า (จัดกลุ่มด้วย Model เดียว ไม่แยกความจุ), ช่องทางขายตามสินค้า, 10 อันดับสาขา/พนักงานขาย, ตารางโปรโมชั่น/ของแถมยอดนิยม
- แบนเนอร์ Hero Banner (สไลด์พร้อมหัวข้อ+คำโปรยทับภาพ) และ Promo Grid บนหน้า Dashboard
- ป๊อปอัพโปรโมชั่นแสดงครั้งแรกของเซสชัน (รูป+หัวข้อ+คำอธิบาย+ปุ่ม CTA หรือรูปเปล่าถ้าไม่ตั้งค่าเพิ่ม)

## รายงาน (Reports)
4 หน้า จัดกลุ่มด้วย **Model อย่างเดียว** (ไม่แยกความจุ) ทุกหน้า:
- **สรุปยอดจองรายวัน** — ตาราง pivot ตามวันที่ + ตามสถานะจอง T/F + เทียบ % รายวัน/ตามกลุ่มรุ่น
- **สรุปยอดรุ่น/แอเรีย/ช่องทาง** — ยอดจองตามรุ่น×ช่องทาง, ตามสินค้า(รวมสี)×ช่องทาง, ตามแอเรีย×รุ่น
- **สรุปยอดจองตามสาขา** — 3 ตาราง (จอง T / จอง F / ผลรวม) กรองได้ตาม Area/สาขา
- **สรุปข้อมูลจองทั้งหมด** — โควต้า/ยอดจอง/คงเหลือต่อหมวดหมู่สินค้า
- **หน้า Target** — เป้าหมายเทียบยอดจองจริงตาม Area

ทุกตารางมีปุ่ม export เป็นรูปภาพ

## ใบเสนอราคา/ใบแจ้งหนี้ (Invoice)
- สร้าง/แก้ไข/อนุมัติเอกสาร (workflow: รออนุมัติ → อนุมัติแล้ว, เอกสารอนุมัติแล้วแก้ไม่ได้ยกเว้น Admin ลบได้)
- ข้อมูลบริษัท/โลโก้/ลายเซ็นผู้อนุมัติตั้งค่าล่วงหน้าได้ในหน้าตั้งค่าระบบ ดึงมาใช้อัตโนมัติทุกเอกสารใหม่
- พิมพ์เป็น PDF ผ่าน browser print (คงโทนขาวดำเป็นทางการ ไม่ใช้ธีมสีของแอป)

## ตั้งค่าระบบ (Settings, Admin เท่านั้น)
- **ชื่อเว็บแอป + โลโก้**: เปลี่ยนชื่อ/อัปโหลดโลโก้แทนไอคอนเริ่มต้น แสดงผลหน้า Login/เมนูข้าง/เมนูมือถือ/ท้ายหน้า
- **ฐานข้อมูล**: Auto Setup (สร้างชีตครั้งแรก, ล็อกไม่ให้รันซ้ำโดยไม่มีสิทธิ์), Drive Folder ID สำหรับเก็บรูปอัปโหลด
- **ตั้งเวลารับจอง** (Booking Period): กำหนดช่วงวันที่เปิด/ปิดรับจองสินค้าหน้า POS
- **Hero Banners**: จัดการสไลด์หน้าแรก — รูป+หัวข้อ+คำโปรย+ลิงก์ปลายทาง
- **Promo Grid**: จัดการแบนเนอร์ตารางโปรโมชั่น — รูป+รายละเอียด+ลิงก์
- **Popup**: จัดการป๊อปอัพแจ้งเตือน — รูป+หัวข้อ+คำอธิบาย+ปุ่ม CTA+ลิงก์ (เว้นว่างทั้งหมด = รูปเปล่าคลิกได้)
- **พื้นหลังหน้า Login**: อัปโหลด/เปลี่ยนรูปพื้นหลัง พร้อมพรีวิว
- **ข้อมูลบริษัท**: ชื่อ/ที่อยู่/อีเมล/โลโก้/ผู้อนุมัติ+ลายเซ็น สำหรับใบเสนอราคา/ใบแจ้งหนี้
- จัดการตารางอ้างอิงทั่วไป (Branches, Channels, Promotions, Interests, GiftMappings, AutoPromotions, Members) ผ่านฟอร์ม CRUD มาตรฐาน กันสร้างรหัสซ้ำทับข้อมูลเดิมทั้งฝั่งฟอร์มและฝั่ง server

## ความปลอดภัยที่มีอยู่แล้ว
Token bearer เซ็นด้วย HMAC (อายุ 30 วัน), รหัสผ่าน salted SHA-256, ตรวจสิทธิ์ตาม role ซ้ำฝั่ง server ทุก action, กัน SKU/ID ซ้ำทั้งฝั่งฟอร์มและ server, กัน formula injection ในช่องข้อความอิสระ, escape HTML ทุกจุดที่แสดงข้อมูลจาก sheet/ผู้ใช้, ราคา/สต๊อก/โปรโมชั่นตอน checkout อ่านจากชีตฝั่ง server เท่านั้นไม่เชื่อค่าที่ client ส่งมา
