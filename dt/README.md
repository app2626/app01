# ระบบบันทึกข้อมูลการขาย / ผ่อนชำระ (Google Apps Script Web App)

Web App สำหรับกรอกข้อมูลการขายแบบผ่อนชำระ บันทึกลง Google Sheets และเก็บรูปสลิปไว้ใน Google Drive

## โครงสร้างไฟล์

```
dt/
├── .clasp.json          # ตั้งค่า clasp (rootDir = src)
├── README.md            # ไฟล์นี้
└── src/                 # ทุกไฟล์ในนี้จะถูก push ขึ้น Apps Script
    ├── appsscript.json  # Manifest: OAuth scopes + ตั้งค่า Web App
    ├── Code.gs          # Backend: doGet, getInitialData, saveData
    └── index.html       # Frontend: Bootstrap 5 + SweetAlert2 + ฟอนต์ Prompt
```

## ตั้งค่าโฟลเดอร์เก็บสลิป (ไม่บังคับ)

1. สร้างโฟลเดอร์ใน Google Drive แล้วเปิดโฟลเดอร์นั้น
2. คัดลอก ID จาก URL: `https://drive.google.com/drive/folders/`**`<FOLDER_ID>`**
3. เปิด `Code.gs` แล้วแก้บรรทัดนี้:
   ```js
   const DRIVE_FOLDER_ID = 'ใส่_FOLDER_ID_ที่นี่';
   ```
   ถ้าไม่แก้ หรือใส่ ID ที่ใช้ไม่ได้ ระบบจะบันทึกรูปไว้ที่ **Root ของ My Drive** ของเจ้าของสคริปต์แทน โดยไม่ Error

ไฟล์สลิปจะชื่อ `Slip_[เลขที่บิล]_[ชื่อ].jpg` และใน Sheet จะเก็บ URL ของไฟล์ (เปิดดูได้เฉพาะคนที่มีสิทธิ์ในไฟล์/โฟลเดอร์นั้น)

## วิธีที่ 1: คัดลอกโค้ดไปวางใน Apps Script บนเว็บ

1. เปิด Google Sheets ไฟล์ข้างบน แล้วไปที่ **ส่วนขยาย (Extensions) → Apps Script**
   (หรือสร้างโปรเจกต์ใหม่ที่ <https://script.google.com>)
2. **Code.gs**: เปิดไฟล์ `Code.gs` ใน Editor (หรือเปลี่ยนชื่อไฟล์ `รหัส.gs` เดิม) ลบโค้ดเดิมออก แล้ววางโค้ดจาก `src/Code.gs`
3. **index.html**: กด **+ → HTML** ตั้งชื่อว่า `index` (Editor จะเติม `.html` ให้เอง) แล้ววางโค้ดจาก `src/index.html`
4. **appsscript.json**:
   - ไปที่ ⚙️ **Project Settings** → ติ๊ก **Show "appsscript.json" manifest file in editor**
   - กลับมาที่ Editor เปิด `appsscript.json` แล้ววางเนื้อหาจาก `src/appsscript.json`
5. กด 💾 บันทึก
6. **อนุญาตสิทธิ์ครั้งแรก**: เลือกฟังก์ชัน `authorizeOnce` ในแถบด้านบน แล้วกด **Run** →
   กด **Review permissions** → เลือกบัญชี → **Advanced → Go to (ชื่อโปรเจกต์) (unsafe)** → **Allow**
   (ฟังก์ชันนี้จะเช็กว่าเปิด Spreadsheet และโฟลเดอร์ได้ แล้วแสดงตัวเลือกทั้งหมดใน Execution log)
7. **Deploy**: กด **Deploy → New deployment** → ไอคอนเฟือง ⚙️ เลือก **Web app**
   - *Execute as*: **Me**
   - *Who has access*: เลือกตามต้องการ (ดูหัวข้อ "ความปลอดภัย" ด้านล่าง)
   - กด **Deploy** แล้วคัดลอก **Web app URL** (`.../exec`) ไปใช้งาน
8. ถ้าแก้โค้ดภายหลัง: **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy**
   (URL เดิมจะได้โค้ดใหม่ ถ้าสร้าง New deployment จะได้ URL ใหม่)

## วิธีที่ 2: ใช้ `@google/clasp` อัปโหลดจาก Terminal ใน VS Code

### ติดตั้งครั้งแรก

```bash
# 1) ติดตั้ง Node.js (LTS) ก่อน แล้วติดตั้ง clasp
npm install -g @google/clasp

# 2) เปิดใช้ Apps Script API ของบัญชีคุณ (ทำครั้งเดียว)
#    https://script.google.com/home/usersettings  ->  Google Apps Script API: On

# 3) ล็อกอิน (จะเปิดเบราว์เซอร์ให้กดอนุญาต)
clasp login
```

### เชื่อมกับโปรเจกต์ Apps Script

โฟลเดอร์นี้มี `.clasp.json` (ผูกกับ scriptId อยู่แล้ว และตั้ง `rootDir: "src"`) ข้ามไปขั้นตอน "อัปโหลดโค้ด" ได้เลย

ถ้าจะผูกกับโปรเจกต์อื่น ให้แก้ `scriptId` ใน `.clasp.json`
(หา Script ID ได้ที่ Apps Script → ⚙️ Project Settings → IDs) หรือสร้างใหม่:

```bash
clasp create --type sheets --title "ระบบบันทึกข้อมูลการขาย" --rootDir src
```

### อัปโหลดโค้ด

```bash
cd "D:/New folder/app01/dt"

# อัปโหลดทุกไฟล์ใน src/ ขึ้น Apps Script (ทับของเดิม)
clasp push

# เปิด Editor บนเว็บ เพื่อ Run ฟังก์ชัน authorizeOnce ครั้งแรกและกดอนุญาตสิทธิ์
clasp open
```

> หมายเหตุ: ใน `src/` ยังมีไฟล์ `รหัส.js` (ไฟล์ตั้งต้นที่มีแค่ `myFunction()` ว่าง ๆ) ลบทิ้งได้ถ้าไม่ใช้
> พอลบในเครื่องแล้ว `clasp push` ครั้งถัดไปจะลบไฟล์นี้บนเซิร์ฟเวอร์ด้วย

### Deploy เป็น Web App

```bash
# ครั้งแรก: สร้าง deployment ใหม่ (จะได้ Deployment ID และ URL)
clasp deploy --description "v1"

# ดูรายการ deployment ทั้งหมด
clasp deployments

# ครั้งต่อไป: อัปเดต deployment เดิม (URL ไม่เปลี่ยน)
clasp push
clasp deploy --deploymentId <DEPLOYMENT_ID> --description "v2"
```

URL ของ Web App คือ `https://script.google.com/macros/s/<DEPLOYMENT_ID>/exec`

> `clasp push` อัปเดตแค่เวอร์ชัน **@HEAD** (ทดสอบผ่าน URL `/dev` ได้ เฉพาะคนที่มีสิทธิ์แก้ไขสคริปต์)
> ผู้ใช้ทั่วไปที่เปิด URL `/exec` จะเห็นโค้ดใหม่ก็ต่อเมื่อรัน `clasp deploy --deploymentId ...` แล้วเท่านั้น

## หน้าตั้งค่าระบบ (แอดมิน)

กดปุ่ม **⚙️ ตั้งค่าระบบ** มุมขวาบนของฟอร์ม หรือเปิด `.../exec?page=settings`

**ตั้งรหัสผ่านแอดมินครั้งแรก**
1. ใน Apps Script Editor เลือกฟังก์ชัน `createAdminSetupCode` แล้วกด **Run**
   (ถ้ารัน `authorizeOnce` ตอนที่ยังไม่มีรหัสผ่าน จะสร้างรหัสให้อัตโนมัติ)
2. ดู **รหัสตั้งค่า** 10 หลักใน Execution log (ใช้ได้ 30 นาที ใช้ได้ครั้งเดียว)
3. เปิดหน้าตั้งค่า → ใส่รหัสตั้งค่า + รหัสผ่านใหม่ (อย่างน้อย 8 ตัวอักษร)
4. **ลืมรหัสผ่าน**: ทำข้อ 1–3 ซ้ำ แล้วกด "ลืมรหัสผ่าน / ตั้งรหัสใหม่ด้วยรหัสตั้งค่า"

**เมนูในหน้าตั้งค่า**
| แท็บ | ทำอะไรได้ |
|---|---|
| รายการ Dropdown | แก้ไขรายการ สาขา / โครงการ / สินค้า / ธนาคาร / จำนวนเดือน (บรรทัดละ 1 รายการ, วางจาก Excel ได้, เรียง ก-ฮ) บันทึกแล้วเขียนทับคอลัมน์ A แถว 2 ลงไปของชีตนั้น |
| โฟลเดอร์สลิป | วาง Folder ID หรือลิงก์โฟลเดอร์ ทดสอบการเข้าถึง แล้วบันทึก (เว้นว่าง = Root ของ Drive) ค่านี้มาก่อน `DRIVE_FOLDER_ID` ในโค้ด |
| ตั้งค่าฟอร์ม | ชื่อระบบ, คำอธิบาย, เปิด/ปิดการบังคับกรอก โค้ดผ่อน / เลขบัตร / ชื่อเจ้าของบัตร / Tid / Trace / รูปสลิป |
| แบนเนอร์ | อัปโหลด / เปลี่ยน / ลบรูปแบนเนอร์ด้านบนหน้าฟอร์ม (ย่อเหลือด้านยาว 1600px, เก็บในโฟลเดอร์สลิป ไม่แชร์สาธารณะ) |
| รหัสผ่าน | เปลี่ยนรหัสผ่าน (ทุกเครื่องที่เข้าสู่ระบบอยู่จะถูกออกจากระบบ) |

**หน้าดูข้อมูล** (ปุ่ม **ดูข้อมูล** บนหน้าฟอร์ม หรือ `.../exec?page=records`)
- ดู 20 / 50 / 100 / 200 / 500 รายการล่าสุดจากชีต Data ใช้รหัสผ่านแอดมินเดียวกับหน้าตั้งค่า
- **แบ็คอัพข้อมูล:** ติ๊กเลือกรายการ (หรือติ๊กหัวตารางเพื่อเลือกทั้งหมด) แล้วกด **แบ็คอัพที่เลือก** ระบบจะคัดลอกแถวไปชีต `BackupData` (สร้างให้อัตโนมัติ มีคอลัมน์ "วันที่แบ็คอัพ" ต่อท้าย) แล้วจึงลบออกจากชีต `Data`
  - ก่อนลบ ระบบตรวจว่าแถวในชีตยังตรงกับที่แสดงบนหน้าจอ ถ้าข้อมูลเปลี่ยนระหว่างนั้น (เช่น มีคนแก้ชีตเอง) แถวนั้นจะถูกข้าม ไม่ลบผิดแถว
  - ดูรายการที่แบ็คอัพแล้วได้ที่ปุ่มสลับ **ชีต BackupData** บนหน้าดูข้อมูล (ดูอย่างเดียว แสดงวันที่แบ็คอัพในรายละเอียด)
  - ถ้าต้องการกู้คืน ให้คัดลอกแถวจาก `BackupData` กลับไปที่ `Data` (ไม่ต้องเอาคอลัมน์ "วันที่แบ็คอัพ")
- กดปุ่ม **+** หน้าแถวเพื่อดูข้อมูลครบทุกช่องและลิงก์สลิป คอลัมน์ในตารางซ่อน/แสดงอัตโนมัติตามขนาดจอ (มือถือ → แท็บเล็ต → โน้ตบุ๊ก → PC)

**ความปลอดภัยของหน้าตั้งค่า**
- รหัสผ่านเก็บเป็น hash (SHA-256 + salt, 1,000 รอบ) ใน Script Properties ไม่เก็บรหัสจริง
- ทุกคำสั่งของแอดมินตรวจ token ที่ Server ทุกครั้ง token หมดอายุใน 6 ชั่วโมง
- ใส่รหัสผิด 5 ครั้ง ระบบจะล็อกการเข้าสู่ระบบ 10 นาที (ล็อกทั้งระบบ เพราะ Apps Script ไม่รู้ IP ของผู้ใช้)
- การตั้งค่าทั้งหมดเก็บใน **Project Settings → Script Properties** (`SLIP_FOLDER_ID`, `APP_TITLE`, `APP_SUBTITLE`, `FORM_REQUIRED`, `ADMIN_*`)

## การทำงานของระบบ

- **เปิดหน้าเว็บ**: แสดง Loading แล้วเรียก `getInitialData()` ครั้งเดียว ดึงตัวเลือกจากคอลัมน์ A ของทั้ง 5 ชีต
  (ตัดค่าว่างและค่าซ้ำออก) ถ้าไม่เจอชีตไหนจะมีแจ้งเตือน
- **แนบรูปสลิป**: ย่อรูปด้วย HTML5 Canvas ให้ด้านยาวไม่เกิน 1280px แล้วแปลงเป็น JPEG คุณภาพ 80% ก่อนส่ง
  (โดยทั่วไปเหลือประมาณ 150–400 KB) และแสดงตัวอย่างรูปก่อนบันทึก
- **บันทึก**: `saveData()` ตรวจข้อมูลซ้ำที่ฝั่ง Server → อัปโหลดสลิปลง Drive → เขียนแถวใหม่ลงชีต `Data`
  โดยใช้ `LockService` กันข้อมูลชนกันเวลาบันทึกพร้อมกันหลายคน ถ้าเขียน Sheet ไม่สำเร็จจะย้ายไฟล์สลิปที่อัปโหลดไปแล้วลงถังขยะ
- **รูปแบบข้อมูลใน Sheet**:
  - เบอร์ลูกค้า, IMEI, เลขที่บิล, เลขบัตรเครดิต, Tid, Trace → ใส่ `'` นำหน้า ให้เก็บเป็นข้อความ (เลข 0 ตัวหน้าไม่หาย และไม่กลายเป็นรูปแบบ 3.57E+14)
  - ราคา, ส่วนลด → เก็บเป็นตัวเลข (ส่วนลดว่าง = 0)
  - ข้อความที่ขึ้นต้นด้วย `= + - @` จะใส่ `'` นำหน้า กันการฝังสูตร (Formula Injection)
- **ตรวจข้อมูลฝั่ง Server**: ทุกช่องจำเป็นต้องกรอก ยกเว้นส่วนลด, ค่าจาก Dropdown ต้องมีอยู่จริงในชีตต้นทาง,
  เบอร์ 9–10 หลักขึ้นต้นด้วย 0, IMEI ตัวเลข 14–16 หลัก, ส่วนลดต้องไม่เกินราคา, สลิปต้องเป็น JPG/PNG/WEBP จริงและไม่เกิน 5 MB

## ความปลอดภัย (ควรอ่าน)

- `appsscript.json` ตั้งไว้เป็น `"access": "ANYONE_ANONYMOUS"` ตามค่าเดิมของโปรเจกต์ แปลว่า **ใครที่มีลิงก์ก็บันทึกข้อมูลได้โดยไม่ต้องล็อกอิน**
  ถ้าใช้ภายในองค์กร แนะนำให้เปลี่ยนเป็น `"DOMAIN"` (Google Workspace) หรือ `"ANYONE"` (ต้องล็อกอินบัญชี Google)
- ระบบเก็บ **เลขบัตรเครดิต** ตามที่กรอก ถ้าเป็นไปได้ให้กรอกแบบปิดบัง (เช่น `4111XXXXXXXX1111` ตามที่พิมพ์บนสลิป EDC)
  และจำกัดสิทธิ์การเข้าถึง Google Sheets / โฟลเดอร์สลิปเฉพาะคนที่จำเป็น
- Scope `drive` เป็นสิทธิ์เข้าถึง Drive ทั้งหมดของเจ้าของสคริปต์ (จำเป็นสำหรับ `DriveApp.getFolderById` และ `createFile`)
